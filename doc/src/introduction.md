# About Updated

*updated* is a software update service that integrates swupdate, hawkbit, and
can accomodate additional requirements, e.g. user consent prompts, through its
plugin system.

Rustdoc documentation for updated can be accessed [here](<https://pages.lis-github.liebherr.com/liebherr/ldc_iot_updated/rustdoc/doc/updated/index.html>).
